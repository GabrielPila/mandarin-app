## Notas Texto 1
### N1-1 我的手机丢了。
He perdido mi móvil.
### N1-2 他们两个星期以后才把护照还给你。
Ellos no me devolverán el pasaporte hasta dos semanas después. El adverbio "才" se
usa para indicar que algo sucede más tarde, más lento o con mayor dificultad de lo esperado.
También significa menor cantidad: 我才吃了三个包子，吃了才一个。
### N1-3 欢迎您再来。
Bienvenido a venir otra vez. Expresión usada por vendedores o anfitriones al despedirse.

## Notas Texto 2
### N2-1 G2次怎么样？
¿Qué te parece el tren de alta velocidad G2? "G2次" se lee como "gāo 2 cì".
### N2-2 我要乘趟子吧。
Quiero tomar este. "趟" es clasificador para indicar el número de viaje o la cantidad de
viajes de ida y vuelta.
### N2-3 我来拿箱子吧。
Déjame llevar la maleta. "来" no expresa acción específica sino el deseo de hacer algo.
### N2-4 后来跟座位旁边的一个学生聊了半小时天儿。
Luego conversé media hora con un estudiante. "后来" y "以后" tienen usos diferentes.
### N2-5 现在坐高铁又快又舒服。
Hoy en día tomar el tren de alta velocidad es rápido y conveniente. Estructura "又…又…"
conecta dos adjetivos simultáneos.
### N2-6 我先睡了两个小时觉。
Primero dormí dos horas. "睡觉", "聊天儿" son palabras separables (V-O) que pueden
tener otro elemento insertado.

## Gramática
### G1 — 把字句 La oración con "把"
"把" se coloca antes del objeto para indicar que la acción lo dispone o afecta de
manera específica. La acción debe tener un resultado o duración.
Estructura: S + 把 + O + V + Pt.aux. "了"; negativa: 没有 + V (sin 把)
Ejercicio G1-I — Práctica de sustitución.
Ejercicio G1-II — Basándose en el ejemplo, forma oraciones.

### G2 — 时间补语 El complemento de duración
El complemento de duración indica la extensión de tiempo de una acción. Se añade
directamente después del verbo. Si el verbo lleva objeto, se repite el verbo.
Estructura: S + (M) + V + (Pt.aux.) + Complemento de duración + (了) + O

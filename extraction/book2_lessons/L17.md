## Gramática
### G1 — 动词"过"表示过去的经验或经历 La partícula "过" para expresar experiencias pasadas
"过" se coloca después del verbo indicando que cierta acción ha sucedido en el pasado.
Negativa: 没(有)…过; Pregunta: …过没有?
Ejercicio G1-I — Práctica de sustitución.
Ejercicio G1-II — Observa las imágenes y escribe oraciones.

### G2 — "好" + V (好听, 好看, 好吃, 好玩)
El adjetivo "好" se usa antes de "听", "看", "吃", "玩" para indicar que algo es
agradable al sentido correspondiente.
Ejercicio G2-I — Práctica de sustitución.

### G3 — 虽然…但是… / 但是 Aunque / A pesar de que
"虽然…但是…" indica una relación adversativa entre las dos cláusulas. "虽然" puede
colocarse antes o después del sujeto de la primera cláusula.
Ejercicio G3-I — Traza líneas para conectar las cláusulas.
Ejercicio G3-II — Observa las imágenes y completa las oraciones.

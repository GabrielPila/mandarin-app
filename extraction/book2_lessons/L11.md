## Notas Texto 1
### N1-1 您刚从西安回北京
Acaba de regresar de Xi'an a Beijing.
La preposición "cóng 从 + S/FN" suele preceder al verbo para indicar el punto de partida
de una acción. El objeto de "从" es una palabra o frase de lugar o tiempo. Por ejemplo,
从北京到上海 / 从学校去商店 / 从八点到十二点都有课。
### N1-2 又去了上海
También irás a Shanghai.
"又" significa "también" o "otra vez". Lin Na acaba de visitar Xi'an y ahora también desea
viajar a Shanghai. Comparación de 又 y 再: ambos indican que la acción ha sucedido (又) o
sucederá (再) al menos una vez más. Por ejemplo,
他又去中国了 / 他明年再去中国。

## Gramática
### G1 — 结构补语(1) El complemento modal (1)
Después de algunos verbos y adjetivos, se añade "得" para expresar el complemento modal.
El complemento modal está formado por un adjetivo o una frase adjetival. "得" debe usar
la partícula "得" para conectar el verbo y el complemento modal.
Estructura: V + 得 + Adj/V; negativa: V + 得 + 不 + Adj/V
Si el verbo lleva objeto, se repite el verbo: (V + O) + V + 得 + Adj.

### G2 — 助词"了"在动词后，表示动作行为的完成或实现
La partícula "了" después del verbo confirma la finalización o realización de una acción.
Forma: V + Núm-Clas/Pron/Adj. + O; negativa: 没（有）+ V

### G3 — 动词重叠 Reduplicación del verbo
Un verbo chino puede repetirse como AA o A-A. La reduplicación de un verbo monosilábico
es "AA" o "A-A". Para verbos de dos sílabas: "ABAB". A veces en forma "AB了AB".
La reduplicación generalmente representa la breve duración o el intento de una acción.

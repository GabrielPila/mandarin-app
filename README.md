# 中文 · Chino Práctico

App personal para aprender mandarín con _El Nuevo Libro de Chino Práctico_
(NPCR, 3ª ed. en español).

- **Flashcards** con repetición espaciada (SRS) + repaso libre por lección
- **Textos**: diálogos del libro y lecturas nuevas graduadas por lección
- Lector con **pinyin**, **tonos** o **traducción** activables, y popup por
  palabra (significado, pinyin, ejemplo)
- Significados en **español o inglés**
- PWA: funciona sin conexión; "Añadir a pantalla de inicio" en iPhone/iPad
- Progreso guardado en el dispositivo, con exportar/importar

Uso personal de estudio.
